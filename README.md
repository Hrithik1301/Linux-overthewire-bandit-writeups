# OverTheWire Bandit Writeups

My personal writeups for the OverTheWire Bandit wargame.

Bandit is a beginner Linux wargame designed to teach 
command-line skills used in real security work.

## What I learned
- SSH, file permissions, special characters in Linux
- Finding files by properties (size, owner, group)
- grep, sort, uniq, strings for log analysis
- Base64, ROT13, compression layers
- SSH key-based authentication
